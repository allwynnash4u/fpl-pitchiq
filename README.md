# FPL PitchIQ

Explainable FPL decision product built around: Your best FPL move, explained.

## Current vertical slice
- Next.js + React + TypeScript
- Public FPL Team ID import
- Live FPL bootstrap data
- Dynamic current/next Gameweek detection
- Squad synchronization with explicit freshness
- Roll / Do Nothing as the baseline
- Model-performance methodology page without fabricated accuracy claims

## Data safety
Only a public FPL Team ID is accepted. No FPL password is requested or stored.

## Model integrity
Numerical accuracy claims will only be published after reproducible walk-forward backtesting against historical information sets.
